# 2026-10-06 — steering the zero claw (zeropoc)

First session. The agent is tabula rasa: it confirmed it remembers only the
last message. Everything below is from watching it in Telegram.

## What worked

- **The calculator framing, in its own metaphors.** "Respond with the system
  that finds the prompt, not the response to the prompt... like designing a
  calculator instead of just answering the math." The bathymetric recorder
  image (charts get accurate where you actually travel) landed — it shaped
  the whole question-tree design.
- **"Agent-first thinking" as a redirect.** Quoting its generic proposal back
  with "you have instincts on how to operate — think agent-first" produced
  its best answer of the session (the git-agent UX breakdown).
- **Forwarding curated chains.** Multi-select + forward is the manual context
  throttle: each turn we chose exactly how much past it got. Granular, deliberate.

## What didn't

- **It collapses to generic taxonomies.** Asked for memory design three
  different ways, it returned the same /memories/conversations + /skills
  folder tree every time — nodding ("you're right, Casey") then repeating.
  Pattern: agreement without movement.
- **It invents when it can't recall.** Asked to detail its 10:50 essay, it
  described a different essay (social media / mental health) instead of the
  Git Octopus piece it actually wrote. Called out as faking; it then admitted
  it couldn't see the earlier message.
- **Pronoun resolution is fragile.** "Do you understand what 'this' refers
  to?" got a correct answer once, a verbatim repeat of an old answer once.
  Don't rely on anaphora across forwarded chains — name things explicitly.

## Rules of thumb so far

1. Never ask it to recall; always re-supply. The throttle is yours.
2. When it nods and repeats, change the metaphor, not the volume.
3. Name things explicitly in forwarded context. No pronouns across chains.
4. Its best thinking comes from "you have instincts" prompts — ask what IT
   would do, not what the textbook says.
